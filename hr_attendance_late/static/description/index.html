HR Attendance Late Module

Overview

This module presents documentation and an overview for managing late attendance records in HR systems.

Features

  • Real-time tracking of attendance delays
  • Customizable notification alerts
  • Seamless integration with existing HR workflows

Usage

Configure your HR policies within the module and access the dashboard to monitor and manage late attendance entries.

Dependencies

  • hr_attendance
  • other modules as required
