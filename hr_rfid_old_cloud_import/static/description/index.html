HR RFID Old Cloud Import Module

Overview

This module extends the core RFID Access Control (hr_rfid) functionalities by enabling data import from an older cloud-based system. It allows seamless transition and synchronization of legacy data.

Features

  • Import all Users and RFID cards
  • Import All Access Control Groups
  • Import all Access Users Rights

Usage

After installation, configure the module settings to connect with your legacy cloud system. Data will be automatically imported and synchronized with the current RFID records.

Installation & Dependencies

This module depends on the core hr_rfid module. Make sure all prerequisite modules are installed prior to configuring this module.
