RFID System Portal Plugin

Overview

This plugin integrates the RFID system with the portal module to enhance access control and management.

Features

  • RFID card management interface
  • Seamless integration with portal
  • Easy configuration and auto-installation

Usage

After installation, configure the plugin according to your portal's requirements. Manage RFID card details seamlessly.

Dependencies

  • hr_rfid
  • portal
