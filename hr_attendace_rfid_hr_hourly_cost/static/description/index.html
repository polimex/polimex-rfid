HR Attendance RFID HR Hourly Cost Module

Overview

This module enhances HR attendance management by integrating RFID functionality with hourly cost computations.

Features

  • Real\-time attendance tracking with RFID
  • Hourly cost calculation based on attendance data
  • Seamless integration with existing HR workflows

Usage

Configure the module settings to match your HR policies and monitor employee attendance along with cost metrics in real\-time.

Dependencies

  • hr_rfid
  • hr_hourly
