RFID Refresh Views

Overview

This module provides refreshed views for RFID functionalities, enhancing the handling and visualization of RFID data.

Features

  • Enhanced user interface for RFID data refresh
  • Smooth integration with existing HR and RFID workflows
  • Optimized performance in displaying RFID records

Usage

After installation, access the updated views through the designated menu paths in the application interface.

Dependencies

  • hr_rfid
  • other modules as required
