RFID Site Manager Module

Overview

The RFID Site Manager module integrates site management functionality with RFID systems to streamline access control and administration.

Features

  • Centralized site management
  • Enhanced RFID access control
  • Real-time monitoring and reporting

Usage

Configure the module settings according to your site's needs. Access the dashboard to manage site and RFID functionalities effectively.

Dependencies

  • hr_rfid
  • portal
