RFID PMS Base

Integrate your Property Management System with RFID access control. This module provides the foundation for managing rooms, guests, and access cards in hotels, residential complexes, and other property management scenarios.

Key Features

🏨 Room Management

Complete room management system with status tracking, cleaning schedules, and guest assignments.

🔑 Card Encoding

Encode RFID cards directly from room assignments with automatic access rights configuration.

👥 Guest Management

Track guest information, check-in/check-out times, and manage multiple cards per room.

🔄 Room Moves

Easy room transfer wizard to move guests between rooms while maintaining access control.

Functionality Includes

  • Room States: Available, Occupied, Cleaning, Maintenance, etc.
  • Card Management: Issue, revoke, and track RFID cards per room
  • Access Control: Automatic door access configuration based on room assignments
  • Reporting: Guest history, room utilization, and card usage reports
  • Multi-property: Support for multiple buildings or properties

Perfect For

  • Hotels and hospitality businesses
  • Student accommodation and dormitories
  • Serviced apartments and extended stay facilities
  • Corporate housing and residential complexes
  • Any property requiring room-based access control

Integration Benefits

  • Seamless integration with hr_rfid access control system
  • Real-time synchronization between PMS and access control
  • Automated card programming based on room assignments
  • Comprehensive audit trail for all room and card activities
