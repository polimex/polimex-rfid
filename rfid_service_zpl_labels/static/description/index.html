RFID Services ZPL Labels

Professional Wristband Printing for RFID Access Control

Transform your visitor management with professional ZPL wristband printing. This module seamlessly integrates with the RFID Service system to generate high-quality wristbands for temporary access control, featuring barcodes, visitor information, and company branding - all printed directly to Zebra printers.

Direct Zebra Printer Integration

Native ZPL Support

Connect directly to Zebra printers through network sockets for instant wristband printing:

  • Direct TCP/IP communication with printers
  • Support for all ZPL-compatible Zebra models
  • Configurable DPI settings (203/300)
  • Built-in printer connection testing
  • No additional print servers required

Smart Wristband Design

Information-Rich Labels

Each wristband contains all essential visitor information:

  • CODE-128 barcode for quick scanning
  • Service type and validity period
  • Visitor name and identification
  • Access permissions and zones
  • Company logo and branding
  • Emergency contact information

Flexible Configuration

Customizable to Your Needs

Adapt the wristband printing system to match your requirements:

  • Adjustable label dimensions (width/height)
  • Multiple printer configurations per company
  • Custom field mapping for visitor data
  • Template-based layout system
  • Multi-language support

Seamless Workflow Integration

Streamlined Operations

Integrate wristband printing into your existing workflows:

  • One-click printing from service records
  • Batch printing for group visitors
  • Automatic data population from RFID services
  • Print preview before sending to printer
  • Reprint functionality for lost wristbands

Multi-Environment Support

Deployment Flexibility

Choose the printing method that suits your environment:

  • Direct Socket Printing: For single-user setups
  • CUPS Integration: Multi-user environments (with cups module)
  • File Export: Save ZPL for manual printing
  • IoT Box: Odoo's hardware integration
  • Third-Party Integration: Via OCA printing modules
