HR RFID Andromeda Import Module

Overview

This module extends the HR RFID system to import data from the Windows-based Andromeda Access Control System, streamlining the data integration process.

Features

  • Import all users and RFID cards
  • Import all Access Control Groups
  • Import all Access User Rights

Usage

After installation, configure the module settings as required. Once configured, the system will automatically import and synchronize data from the Andromeda system.

Installation & Dependencies

This module depends on the core hr_rfid functionalities. Ensure all prerequisite modules are installed before using this module.
